# 利润与定价

很多链接不是卖不动，是**卖得越多亏得越多**。先把单件账算到分。

## 适用场景

- 新品定价，不知道定多少既有竞争力又有利润
- 准备降价/涨价/上 Coupon，想先看影响
- 老板问“这个品到底赚不赚钱”
- 广告 ACOS 目标定多少才合理
- FBA 和 FBM 该怎么选

不适用：广告结构（用「广告架构与预算」）；类目整体评估（用「类目深度评估」）。

## 硬规则：FBA 和 FBM 必须分两列

两种履约方式**只差尾程**，其余项目完全一样：

| 项目 | FBA | FBM |
|---|---|---|
| 尾程 | FBA 配送费（按尺寸重量） | 自发货运费（头程到仓 + 出库派送，或海外仓操作费 + 派送） |
| 仓储 | FBA 月度仓储费 + 旺季附加费 | 海外仓仓储费（自己发货则基本为 0，但要算库存资金占用） |

所以**不要只算一套**。同一张表里 FBA 一列、FBM 一列，差异一目了然。

如果用户明确说自己只做一种，另一种照样列出来，但金额写「不适用」——方便他对比以后再决定。

## 先收数字

逐项确认，缺失就标「假设」并给区间：

| 项目 | 说明 |
|---|---|
| 售价 | 当前或计划 |
| 采购成本 | 含税/不含税要说明 |
| 头程 | 海运/空运/快递，单件摊（FBA 算到仓，FBM 算到门/海外仓） |
| **FBA 配送费** | 按尺寸重量、当前费率 |
| **FBM 尾程运费** | 自发货派送费，或海外仓出库+派送 |
| 佣金 | 通常 15%，部分类目不同 |
| 退货率 | FBA 有退货处理费；FBM 退货要自己承担来回运费 |
| 仓储/库存费 | FBA 月度+旺季；FBM 看是否用海外仓 |
| 广告占比 | 或目标 ACOS |
| Coupon/促销 | 折扣、秒杀费 |
| 汇率/支付/税 | 需要时 |

费率会变，先让用户确认当前站点费率；没有就用最近公开数据并标注。

## 计算

```
净利 = 售价
     - 采购 - 头程 - 尾程 - 佣金
     - 退货摊销（售价 × 退货率 × 损耗系数）
     - 仓储 - 促销 - 广告
```

```
净利率 = 净利 / 售价
广告前毛利 = 售价 - 采购 - 头程 - 尾程 - 佣金 - 退货 - 仓储 - 促销
盈亏平衡 ACOS = 广告前毛利 / 售价
```

**FBA 和 FBM 各算一遍**，尾程那一项换掉即可。

### 价格阶梯

给 3–5 个价格点（如 $24.99 / $27.99 / $29.99 / $32.99），每个价格点算：

- FBA 净利率 / FBM 净利率
- 盈亏平衡 ACOS（按主推方式）
- 相比当前价的销量弹性假设（没有数据就说明是假设）

### 敏感性表

行：售价；列：广告占比（0% / 10% / 15% / 20% / 25%）；单元格：净利率。按主推履约方式算，表头注明是 FBA 还是 FBM。

## 输出格式（结构固定）

## 红线

1. 不编费率、汇率、退货率；查不到就让用户填。
2. 所有假设单独列，不混进"实测"。
3. 不把"净利"算成"毛利"，不遗漏退货和仓储。
4. **不许只算一套履约方式**——FBA 和 FBM 必须各一列。
5. 不承诺涨价后销量不变。
6. 涉及税务/合规，提示咨询当地专业机构。
