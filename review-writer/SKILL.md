# 买家评论生成

目标：写出来像**真买家**写的，不是卖家在自夸。

## 对话里要问清四件事

1. **产品**：什么品类（办公椅 / 电竞椅 / 儿童椅）
2. **夸哪些点**：用户给（坐垫软、靠背高、面料透气、好安装…）
3. **长度**：短（30–60 词）/ 中（80–120 词）/ 长（150–220 词）
4. **条数和语种**：默认 10 条英文（美国站），要中文另说

用户没说就按默认：10 条、中长混合、英文。

## 写法（这是关键的几条）

**每条必须有一个具体的人**

- 谁：上班族 / 学生 / 带娃的妈 / 打游戏的 / 养猫的 / 腰不好的中年人
- 在哪：出租屋书桌 / 家里书房 / 宿舍 / 车库改的工作间
- 用了多久：两周 / 一个月 / 三个多月

**只夸用户给的点，但用生活细节落地**

| 用户给的点 | 别这么写 | 这么写 |
|---|---|---|
| 坐垫软 | The cushion is very soft. | 我家猫现在天天趴在这椅子上，我起来它立马占座。坐垫比我想的软，坐一下午屁股不麻。 |
| 靠背高 | The backrest is tall. | 我 185cm，之前那把椅子靠背只到我肩膀，这把能靠到后脑勺，往后仰的时候脖子不用悬着。 |
| 面料透气 | The fabric is breathable. | 夏天穿短裤坐一天，起来大腿不粘椅子——之前那把皮的，夏天我必须垫条毛巾。 |

**允许一点小瑕疵**（可信度来源）

- 安装花了 40 分钟，说明书图有点小
- 轮子在地毯上有点阻力，木地板上很顺
- 味道第一天有点，散两天就没了

**禁止**

- 堆形容词：amazing / perfect / incredible / best ever 连着用
- 通篇只有一个点反复说（“很舒服”说五遍）
- 像宣传语：“ergonomic design”“premium quality materials”
- 每条都用同一个句式开头（“I bought this...”）

**要有变化**

10 条里：人设不重复、场景不重复、开头句式不重复、至少 2 条带小瑕疵。

## 输出流程

1. 按上面的规则写好评论，每条带 `persona / scene / used / points / text / text_zh`
2. 用 `write_file` 写到工作区根目录的 `review-input.json`（结构见 `scripts/reviews.py` 顶部注释）
3. 告诉用户「点运行导出 Excel」，或直接说已经写好了

Excel 两张表：`Comments`（外语原文 + 人设场景）和 `中文对照`。

## 红线

1. **不编具体数据**：不写“承重 300 磅我坐了半年没塌”这种用户没给的参数
2. **不写医疗功效**：不说“治好了我的腰突”，最多“腰没那么酸”
3. **不冒充真实订单**：这是文案素材，不要写成“verified purchase”口吻
4. **中文对照要与外语一致**，不是另写一版
