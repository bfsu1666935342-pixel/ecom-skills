# 市场机会扫描（初筛）

三分钟判断**值不值得花时间深入评估**。不出 HTML、不写 data.json、不判断"能不能成"。

## 什么时候用

| 用 | 不用 |
|---|---|
| 这个类目 / 产品能不能做 | 要一份可交付的类目报告 → 用「类目决策报告」 |
| 1688 看到一个货，想知道亚马逊有没有生意 | 单个 ASIN 的流量 / 广告诊断 |
| 几个方向里先砍掉明显不行的 | 已有完整数据、要算到小数点 |

## 输入清单

按顺序问。**问不到就降级，并在结论里写 `unknown`，不要猜。**

1. 产品 / 类目（英文词最好）
2. 站点（默认 US）
3. **包装尺寸（英寸，长×宽×高）+ 包装重量（磅）** ← 没这个 FBA 算不了，必须问
4. 1688 参考价（没给 → 利润算不出来，标 `unknown`）
5. 目标售价（没给 → 用下面的 P25）

## 第 1 步 · 锁类目并取数（2–3 次 MCP 调用）

| 目的 | 工具 | 拿什么 |
|---|---|---|
| 锁节点 | `mcp__sorftime__category_name_search` | 用户只给中文/模糊词时先确认 Node；多候选必须让用户选 |
| 需求与趋势 | `mcp__sorftime__category_report`、`mcp__sorftime__category_trend` | 月销量规模、近 24 个月走势、峰值月与谷值月 |
| 价格与竞争 | `mcp__sorftime__category_products` | Top100 的价格分位、评论数、品牌集中度、上架时间 |

工具名以「数据源」页测试结果为准；换了数据源（SIF）就换成实际暴露的名字。

取不到数据就停下来说缺什么，**不要用记忆里的数字补**。

## 第 2 步 · 定价：看分位，不看均价

把 Top100 的售价从小到大排：

| 位置 | 含义 | 怎么用 |
|---|---|---|
| **P25** | 有 25% 的链接比它便宜 | **算利润用这个**：新品抢位的价格 |
| **P50** | 中位数 | 市场标准价，参考 |
| **P75** | 只有 25% 比它贵 | 中高端，要有品牌或差异才够得着 |

**为什么不用均价**：Top100 里混着配件、单只装、清仓低价款，也混着套装高价，均值是个没人真正在卖的价格。

**为什么用 P25 算利润**：新品没评论、没排名，拿不到中位价。用 P50 算出来的是"等你有 500 条评论之后"的利润。用 P25 算是压力测试——**P25 都能活，这生意才安全**。

返回字段：`tier` 归段、`fee` 配送费、`fuel` 含 3.5% 燃油、`cuft` 体积、`storageMo` 单件每月仓储费。

**这个表只覆盖美国站、非服装、非危险品。** 服装加 5–15%；危险品直接判红旗。

## 第 4 步 · 算账

```
落地成本 = 1688价 × (1 + 头程率 + 关税率) + 包装质检
佣金     = 售价 × 15%
FBA      = 第 3 步的 fuel
仓储     = storageMo × 在库月数
广告     = 售价 × 广告占比
退货     = 售价 × 退货率
入库配置 = $2/件（占位，待补官方费率）
净利     = 售价 − 落地 − 佣金 − FBA − 仓储 − 广告 − 退货 − 入库
净利率   = 净利 ÷ 售价
```

三档参数（全部标成「假设」，不要写成实测）：

| 参数 | 悲观 | 中性 | 乐观 |
|---|---|---|---|
| 头程率 | 30% | 20% | 12% |
| 关税率 | 25% | 10% | 0% |
| 广告占比 | 18% | 12% | 8% |
| 退货率 | 8% | 5% | 3% |
| 在库月数 | 3 | 2 | 1.5 |

头程按品类微调：轻小件 8–12%，中件 15–25%，大件/抛货 30–50%。

## 第 5 步 · 红旗（初筛只拦"确定不能做"和"算不过账"）

### A 类 · 一票否决（法规 / 平台不让做）

| 红旗 | 怎么查 |
|---|---|
| 功效宣称：杀菌 / 杀螨 / 驱蚊 / 治疗 / 减肥 | 问用户一句话；命中就要走 EPA / FDA，直接否 |
| 面向 12 岁以下儿童 | 问用户；需要 CPC / CPSIA 报告 |
| 食品接触 / 入口 / 长期接触皮肤 | 问用户；需要 FDA 食品级或化妆品合规 |
| 含锂电池 / 气雾罐 / 液体 / 强磁 / 易燃 | 问用户；要 UN38.3 + MSDS，货代常拒收 |
| 市电供电（插墙） | 需要 UL / ETL，周期 2–3 个月 |
| 含无线发射（蓝牙 / WiFi / 遥控） | 需要 FCC ID |
| 类目 gated（需审批） | 让用户去后台试上架 |
| 医疗器械 / 隐形眼镜 / 高功率激光 | 平台政策直接限制 |

### B 类 · 一票否决（经济上不成立）

| 红旗 | 判定 |
|---|---|
| 进大件档 | 发货重量 > 20 lb 或体积重超限；配送费 $15 起 |
| 低客单 + 高成本 | P25 < $15 且落地成本 > 售价 40% |
| 高退货品类 | 服装鞋、易碎、需安装 |
| 强季节性 | 旺季销量占全年 40% 以上 |
| 盘子太小 | 类目月销 < 300 件 |

### C 类 · 不否决，写进结论

| 风险 | 怎么查 |
|---|---|
| 大卖 / 自营垄断 | CR5 高、Amazon Basics 在售、Top10 评论中位数 > 1000 且近 12 个月无新品进榜 |
| 外观 / 实用专利 | **初筛查不了**，只提示"建议做专利检索"，不下结论 |
| 认证周期长 | 需要认证但用户还没有 |
| 售后复杂 | 电子 / 机械类，推高差评与退货 |

## 第 6 步 · 判定

| 结论 | 条件 |
|---|---|
| **放弃** | 命中任一 A 类；或中性净利率 < 10%；或单件净利 < $10；或盘子太小 |
| **谨慎** | 中性净利率 10–20%；或命中 B 类；或竞争门 warn |
| **值得深挖** | 中性净利率 ≥ 20%，无 A 类，竞争门 pass，需求不是下滑 |

**大件（进大件 / 超大件档）另加两条**：单件净利 ≥ $40 且净利率 ≥ 20%，否则降一档。大件资金重、周转慢，容错空间小。

## 红线

1. **没给 1688 价 → 利润写 `unknown`**，不许用网络搜来的价当采购价。
2. **没给包装尺寸重量 → 不许猜**，先问，问不到就在结论里写"FBA 无法计算"。
3. 1688 的货和 Top10 不是同款时，**不做比价**，先让用户对齐形态和规格。
4. 类目数据只来自工具返回，拿不到就说拿不到。
5. 服装、危险品、需要认证的类目，先提示，别硬算。
6. **不判断"能不能成"**，只回答"要不要继续看"。
